# Netflix Clone

A responsive Netflix clone landing page with a modern streaming UI, built using HTML and CSS.

## Features

- Responsive layout for mobile, tablet, and laptop screens
- Netflix-style hero banner with email call-to-action
- Trending movies section with responsive cards
- Membership benefits section
- Frequently Asked Questions accordion
- Responsive footer and language controls

## Built with

- HTML5
- CSS3
- Font Awesome

## Run locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Note

This is a frontend practice project. The sign-in and email forms are visual UI elements and do not connect to a backend.
